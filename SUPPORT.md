# Support

Coodra is maintained by Matrix Maven.

## Bugs

Open a GitHub issue with:

- The Coodra CLI version from `coodra --version`.
- Your operating system and Node.js version.
- The agent you were using.
- Whether you are running solo mode or team mode.
- Reproduction steps and `coodra doctor --json` output.

## Security

Do not open public issues for vulnerabilities. Follow
[`SECURITY.md`](SECURITY.md) and report privately to `info@matrixmaven.co`.

## Questions

Start with the public developer docs at
<https://matrix-maven.github.io/Coodra/docs/>. If something is unclear, open a
GitHub issue or discussion with the section you were reading and what you
expected to find.

## Commercial Or Company Contact

For Matrix Maven or commercial questions, email `info@matrixmaven.co`.
